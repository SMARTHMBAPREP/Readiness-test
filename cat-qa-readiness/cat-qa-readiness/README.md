# CAT QA: Algebra Readiness (IMS Jaipur)

Static site: a timed 22-question readiness test and a 40-question practice sheet.

- `index.html`: landing page
- `test.html`: the timed test (self-contained, no dependencies)
- `files/`: practice sheet (PDF and Word)

Deploy: push to GitHub, then Settings > Pages > Deploy from branch > `main` / root.
